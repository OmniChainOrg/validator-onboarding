# 🛡️ OmniChain Validator Onboarding Guide

Welcome to **OmniChain DevNet-2** — where science, not speculation, is what we validate.

## ✅ How to Become a Validator

1. Fork this repository
2. Add your validator entry to `validators.json`
3. Include your validator moniker, public key, and any plugin references
4. Submit a pull request for review

## Example Entry
```json
{
  "moniker": "OpenValidator_X",
  "public_key": "omnipub1addwnpepq...",
  "plugins": ["model_checker.py"]
}
```

## 🔧 Plugin Requirements
- Use provided `plugins/model_checker.py`
- Or submit your own hash validation script
